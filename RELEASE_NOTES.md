# Obtainium-PC v1.0 - Early Access

This is the first public release of Obtainium-PC, a native Windows (WinUI 3) app that tracks apps by their release pages, tells you when a new version is out, and downloads it. It is based on the idea and design of Obtainium by ImranR98.

## Downloads
- Obtainium-PC-v1.0-win-x64-Setup.exe: per-user installer, no admin rights needed, .NET runtime bundled.
- Obtainium-PC-v1.0-win-x64-portable.zip: unzip anywhere and run ObtainiumPC.exe, .NET runtime bundled.
- SHA256SUMS.txt: checksums of both files.

Requires Windows 10 1809 or newer, 64-bit.

## Early Access
Obtainium-PC is new. Please report problems at https://github.com/StarsDust01/Obtainium-PC/issues.
